# Version 10.0.0

## Breaking Changes
- Move configuration provider Autofac registration extensions from `LTs.Configurations.Extensions.ConfigurationProviderRegistrationExtensions` to `LTs.Configurations.DependencyInjection.RegistrationExtensions`.
- Move Autofac generic registration extensions from `LTs.DependencyInjections.Extensions.AutofacRegisterExtensions` to `LTs.DependencyInjections.DependencyInjection.RegisterExtensions`.
- Move test logger registration extensions from `LTs.TestUtils.Loggers.TestLoggerRegistrationExtensions` to `LTs.TestUtils.Loggers.DependencyInjection.RegistrationExtensions`.
- Rename `LTs.TestUtils.Tests.DisposableTest` to `LTs.TestUtils.Tests.BaseTest`.
- Move `TestLoggerProvider` into the `LTs.TestUtils.Loggers` namespace.
- Move HTTP handler registration extensions from `LTs.Web.HttpHandlerRegistrationExtensions` to `LTs.Web.DependencyInjection.RegistrationExtensions`.
- Move HTTP content and string web extensions from `LTs.Utils.Extensions.Web` to `LTs.Web.Extensions`.
- `BeSameJsonIgnoringExtraFieldsAs` in `LTs.TestUtils.FluentAssertions` is now obsolete. Have been replaced by `BeSameJsonAs` with `JsonAssertionOptions` for ignoring extra fields.

## Changes
- Add `net10.0` support across all libraries and test projects while keeping `net8.0` support.
- Add `LTs.Json` as a new NuGet package library.
- Add `ParseAsJToken()` extension in `LTs.Json`, with `JsonDateParseType` support for string, `DateTime`, and `DateTimeOffset` date parsing.
- Add `ToJson()` extensions `LTs.Json`.
- Update package references for the supported target frameworks.
- Consolidate package references shared by `net8.0` and `net10.0`.
- Add `TypeExtensions.IsCollectionType()` in `LTs.Utils.Extensions.Types`.
- Update configuration value conversion so collection types fail when the configuration value cannot be converted to a collection.
- Add null-key validation for `FromKeyedServicesAttribute` Autofac parameter resolution.
- Add `JsonAssertionOptions` for `BeSameJsonAs` in `LTs.TestUtils.FluentAssertions`.
- Add fluent JSON assertion options for ignoring extra fields and excluding JsonPath paths, including wildcard paths such as `values[*].id`.
- Add JSON assertion matchers with `WithMatcher()` to compare selected JsonPath values by custom FluentAssertions callbacks.
- Update JSON assertions to report all mismatches found in a comparison instead of only the first mismatch.
- Update `GlobalSuppressions.cs` files across projects.
- Refresh project README files to match the current public APIs and namespaces.
- Move test-only support types into test infrastructure folders.
- Update tests for .NET 10 support and renamed registration/base-test APIs.
- Adapt `LTs.Configurations` from `ScSc.Configurations`, including default configuration loading, AppConfig support, and JSON string configuration sources.
- Add unit tests for `AppConfigConfigurationLoader`, `ConfigurationBuilderExtensions`, and updated `LoadConfigurationExtensions` coverage.
- Add `LTs.Logging` as a new NuGet package library with Serilog configuration, log transformations, and Autofac registration extensions.
- Add unit tests for `LogConfigurator`, log configuration loading, sink wrappers, and periodic flush behavior.
- Fix `Wait.ForAsync` timeout handling so conditions that exceed the timeout always throw.
- Widen timing tolerances in `WaitTest` to reduce thread-pool scheduling flakes.
- Add `LTs.Hosting` as a new NuGet package library with default host application builder extensions for Autofac, Serilog, and Windows Service registration.
- Add unit tests for `HostApplicationBuilderExtensions`.
- Add `TypedConfigurationLoader` in `LTs.Configurations` for metadata-driven typed configuration binding and Autofac registration.
- Add unit tests for `TypedConfigurationLoader` covering required-property validation, defaults, and post-load configuration transforms.
- Add repository rules for typed configuration, host composition, test method regions, and JSON-based test configuration setup.
